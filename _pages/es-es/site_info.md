Este sitio web está construido con [Jekyll](https://jekyllrb.com/) utilizando el tema [multi-language-al-folio](https://github.com/george-gca/multi-language-al-folio). Está alojado por [GitHub Pages](https://pages.github.com/). Un agradecimiento a [Maruan Al-Shedivat](https://maruan.alshedivat.com/) y [George C. de Araújo](https://george-gca.github.io/) por su increíble trabajo en los temas [al-folio](https://github.com/alshedivat/al-folio) y [multi-language-al-folio](https://github.com/george-gca/multi-language-al-folio), respectivamente, que hicieron posible este sitio web.

El código y el contenido de este sitio web se comparten abiertamente en GitHub bajo la [licencia MIT](https://es.wikipedia.org/wiki/Licencia_MIT); siéntete libre de adaptarlo para tus propios propósitos. Puedes encontrar el repositorio aquí: [<i class="fa-brands fa-github"></i> BCEM-UniAndes.github.io](https://github.com/BCEM-UniAndes/BCEM-UniAndes.github.io).
